Row Fixer Plus 1.2.0 brings both stores onto the same version. Chrome Web Store was live on 1.0.0 while Firefox had 1.0.1 in review, so this release republishes both from one build.

- Added a "Support on Ko-fi" link to the popup footer, next to the theme, project, and about controls.
- Chrome Web Store and Firefox Add-ons now ship the identical 1.2.0 package.
- Installation instructions cover the Chrome Web Store listing, the pending Firefox listing, and building from source.
- Customise YouTube grid layouts and separate channel-page settings.
- Hide Shorts, Playables, and channel avatars; choose light or dark popup appearance.
- Preferences stay on your device. No analytics or personal data collection.
- Firefox requires version 142 or newer. The two validator warnings originate in the unmodified React DOM renderer; reviewer notes and matching source are included.

Store review and publication happen independently, so submission does not mean either store has approved the release.
